Preface

Somewhere on your hard drive there is a folder with a paper in it, and in that folder there is a file called figure1.pdf.

Where did it come from? Which script made it? Was that script the current version of the script, or the one from before you fixed the bug in the data-generating function? If a reviewer asks you to change the sample sizes from 50, 100 and 400 to 50, 100, 400 and 1000, how many things do you have to remember to rerun, and in what order, before the number in the abstract is right again?

Most of us answer these questions with memory and discipline. Both work fine until the project gets big, or a coauthor touches it, or you come back to it after eight months. This tutorial is about answering them with a file instead.

A workflow manager is a program that you tell, once, which files depend on which other files and what command turns one into the other. After that it will build anything you ask for, run only what is actually out of date, and refuse to let a figure in your manuscript be older than the code that made it (unless you explicitly override it which isn’t easy to do). This tutorial focuses on one particular workflow manager: Snakemake.

Note

This tutorial reflects a combination of snakemake best practices any my own personal experiences. It also is also not comprehensive, certainly not in all that is possible with snakemake (which I have just begun to scratch the surface on) but even in what I have experimented with. It is meant to hit on what I see is an important foundation to get your creative juices flowing, so you can see how powerful snakemake is and imagine that how much further you can take it than what is introduced here.

Who this is for

Statisticians and biostatisticians who write R, run simulations, and produce manuscripts or analysis reports. You should be comfortable in R. You do not need to know Python (Snakemake is written in Python, and its files are Python, but you will need about five minutes’ worth of it, all of which is explained), and you do not need to have used make or any other build tool.

Everything here runs on a laptop. However, one of Snakemake’s (many) party tricks is that the same workflow can be dispatched to a cluster by adding a configuration file and changing nothing else, but that is out of scope; Where to go next points at where to read about it when you need it.

What we build

One example runs through most of the book. It is a small simulation study of a problem every biostatistician has been asked about: what happens to confidence intervals when the model was chosen using the same data.

In this example we will: generate data, select variables by forward selection, and compare the intervals you get by naively refitting against the intervals you get by splitting the sample. Then we compute this over a grid of sample sizes and correlation levels, turn the results into a figure and a table, and compile the whole thing into a manuscript — so that changing one line of the simulation code and typing snakemake rebuilds the PDF, correctly, every time.

Installing Snakemake

Snakemake is a Python package. Once you have a Python setup you like, install it there. E.g.:

python3 -m pip install snakemake

Check that it worked:

snakemake --version

This “book” was written against Snakemake 9.13. Version 8 introduced a number of changes to how cluster execution is configured, and a few flags used here do not exist in version 7 or earlier.

You will also want R with optparse and ggplot2; 6  Building a manuscript additionally uses tidyr, kableExtra and a LaTeX installation, and 7  A data analysis pipeline uses knitr and Quarto. Each example’s README.md lists what it needs.

Getting the examples

Every code block in this book is printed from a file in the examples/ directory of the tutorial repository, and every terminal transcript is pasted from a real run of that code. Nothing here is pseudocode. Clone the repository and follow along:

git clone https://github.com/lharris421/snakemake-tutorial.git
cd snakemake-tutorial/examples/01-first-rules
snakemake --cores 2
